# Roboto Condensed

`RobotoCondensed-Regular.ttf` and `RobotoCondensed-Bold.ttf` are static 400 and 700 weight instances generated from
Google Fonts' `RobotoCondensed[wght].ttf` using FontTools. The source font is from Roboto v3.008 and is distributed
under the SIL Open Font License 1.1 included in `OFL.txt`.

Source: <https://github.com/google/fonts/tree/main/ofl/robotocondensed>
